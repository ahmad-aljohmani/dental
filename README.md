# موقع عيادة عافية

موقع داخلي لعيادة الأسنان، مبني باستخدام PHP وHTML وCSS وJavaScript. جميع صفحات الموقع تتطلب تسجيل الدخول، ولكل طبيب سجلات زياراته الخاصة.

## المتطلبات

- PHP 8 أو أحدث.
- امتداد PDO SQLite مفعّل.

## إنشاء حسابات الأطباء لأول مرة

من داخل مجلد المشروع شغّل PHP الخاص بـ XAMPP:

```powershell
& 'C:\xampp\php\php.exe' setup-doctors.php
```

سينشئ الأمر ثلاثة حسابات بكلمات مرور عشوائية، ويعرض بيانات الدخول مرة واحدة في سطر الأوامر. احفظ كلمات المرور في مكان آمن؛ لا تُخزّن كلمات المرور كنص واضح. لن يغيّر الأمر قاعدة بيانات فيها حسابات مسبقًا.

## حساب مدير النظام

بعد إنشاء حسابات الأطباء، أنشئ حساب المدير مرة واحدة:

```powershell
& 'C:\xampp\php\php.exe' setup-admin.php
```

اسم مستخدم المدير هو `admin`، ويعرض الأمر كلمة مرور عشوائية مرة واحدة. سجّل الدخول بهذا الحساب لفتح «إدارة الحسابات»، وإضافة الأطباء أو تغيير أسماء المستخدمين وكلمات المرور أو تعطيل الحسابات. اترك حقل كلمة المرور فارغًا للإبقاء عليها؛ تعيين كلمة مرور جديدة أو تغيير اسم المستخدم ينهي جلسات الطبيب النشطة.

صفحة الإدارة للمستخدم ذي صلاحية المدير فقط. لا يمكن تعطيل حساب المدير من هذه اللوحة، كما يحتفظ النظام بمواعيد الطبيب عند تعطيل حسابه.

## التشغيل

```powershell
& 'C:\xampp\php\php.exe' -S localhost:8000
```

افتح `http://localhost:8000` وسجّل الدخول بحساب مدير النظام أو أحد حسابات الأطباء.

## قاعدة البيانات

تُحفظ حسابات الأطباء والمواعيد في `appointments.sqlite` داخل مجلد النظام المؤقت `clinic-booking-hhh`، خارج مجلد الموقع. لتحديد مجلد آخر، عيّن متغير البيئة `APPOINTMENTS_DB_DIR` قبل تشغيل PHP. خذ نسخة احتياطية من قاعدة البيانات إذا احتجت الاحتفاظ بها؛ مجلد النظام المؤقت ليس بديلًا عن سياسة النسخ الاحتياطي.

## سجلات زيارات الأسنان

من صفحة «تسجيل زيارة» يسجل الطبيب اسم المريض وبيانات التواصل والعمر والجنس وتاريخ الزيارة، وملخص الحالة والتاريخ المرضي والحساسية والأدوية والعلاج. يتيح مخطط الأسنان اختيار الأسنان الدائمة واللبنية حسب ترقيم FDI. تظهر هذه البيانات في «سجلات المرضى» للطبيب الذي أنشأها فقط.

تُخزّن السجلات الطبية محليًا في SQLite دون تشفير على مستوى قاعدة البيانات؛ احمِ الجهاز ومجلد قاعدة البيانات، واستخدم HTTPS عند إتاحة الموقع عبر الشبكة، ولا تسجل إلا البيانات اللازمة. خذ نسخًا احتياطية آمنة ومنتظمة.

كل زيارة مرتبطة بالطبيب الذي سجلها، ولا تعرض قائمة السجلات إلا سجلات حساب الطبيب المسجّل دخوله. ترحّل الصفحة أعمدة الزيارات الجديدة إلى قاعدة البيانات الحالية تلقائيًا دون حذف المواعيد السابقة.
